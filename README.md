# Raptor Race

A portrait 3D runner for iPhone where you play real feathered dinosaurs in the places and times they lived.

Play the latest build: https://drew879.github.io/raptor-race-fable/

- `npm run dev` runs it locally.
- `npm run build` makes the production build. Every push to `main` deploys it.
- `npm run art` rebuilds the 3D models from the Blender scripts in `art/`.
- `docs/NOTES.md` has decisions and progress.
